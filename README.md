# Kaveer's daily builds

One small hands-on build a day, done by hand. No AI.

I'm a DevOps engineer (Azure DevOps CI/CD, AWS, PowerShell, SQL Server, QA and performance testing) growing into
platform engineering and AI infrastructure. Each folder is one build, started from the basics and climbing to
senior and lead level: Linux and shell scripting, Docker, CI/CD pipelines, cloud, Terraform/Bicep, Kubernetes,
observability, networking and security, test automation, and on the AI side: running models, MLOps and agents.

## Rules

- **No AI.** Official docs, man pages and search are fine. Everything here is typed by me.
- One concept per build, roughly 30–60 minutes, each with a README of what I learned.

## Layout

```
<yyyy-mm-dd>-<slug>/
  README.md     what the challenge was, what I learned, what I'd do differently
  ...           scripts, Dockerfiles, pipelines, IaC, docs
```
